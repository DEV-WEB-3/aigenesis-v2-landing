# Inventario de media de la alianza (Aitech → G1)

Assets descargados de aitechone.io (misma alianza, uso global de las comunidades),
self-hosteados para reusar y mejorar en la web G1. Ruta base: `public/g1/media/`.

- **curados** (renombrados, en uso en cristales): `public/g1/media/*.mp4|*.jpg`
- **librería completa** (mirror organizado): `public/g1/media/aitech/…`
- **logos de producto**: `public/g1/media/aitech-brand/…`

> Excluido: `about/video-oficial.mp4` (99.8 MB, supera el límite de GitHub y no se usa).
